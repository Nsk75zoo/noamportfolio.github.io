# Portfolio – Goldstein Noam

Portfolio BTS SIO (option SISR) – site statique (HTML/CSS/JS).

## Structure
- `index.html` : la page du portfolio (tout le contenu se modifie dans le bloc `PORTFOLIO`)
- `docs/` : documents PDF (tableau de synthèse E5, etc.)
- `assets/images/` : photo et images (ex. `photo.jpg`, puis `photo: "assets/images/photo.jpg"` dans `index.html`)
